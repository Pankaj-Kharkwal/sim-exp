## KEY INTERFACE DEFINITIONS

### McpServerWithStatus
- Properties: id, name, description, transport, url, headers, timeout, retries
- Status: enabled, connectionStatus, lastError, toolCount
- Metadata: createdAt, updatedAt, lastConnected, totalRequests, lastUsed, lastToolsRefresh
- Soft Delete: deletedAt

### McpTool
- name: string
- description: string
- inputSchema: JSON schema for parameters
- serverId: string
- serverName: string

### StoredTool (in workflow)
- type: 'mcp' | 'custom-tool' | blockType
- title: string
- toolId: string (format: mcp-{serverId}-{toolName})
- params: Record<string, string>
- isExpanded: boolean
- usageControl: 'auto' | 'force' | 'none'
- schema, code: for custom tools

## IMPORTANT PATTERNS

### Tool ID Format
- Built-in tools: blockType (e.g., "slack", "gmail")
- Custom tools: "custom-{functionName}"
- MCP tools: "mcp-{serverId}-{toolName}"

### API Response Format
```
{
  success: boolean
  data?: T
  error?: string
}
```

### Subblock Types (MCP Block)
1. mcp-server-selector: Choose MCP server
2. mcp-tool-selector: Choose tool from server
3. mcp-dynamic-args: Input tool parameters

### Parameter Types in MCP
- string, number, boolean
- array, object
- enum (with options)
- Required vs optional

### Transport Types
- streamable-http (primary)
- http (basic)
- sse (server-sent events)

### Protocol Versions
- 2025-06-18 (latest, OAuth 2.1)
- 2025-03-26 (Streamable HTTP)
- 2024-11-05 (legacy)

## EXECUTION FLOW

1. User selects tool in workflow block
2. Configures parameters
3. Workflow execution engine encounters tool block
4. Parameters resolved (variables substituted)
5. Type coercion applied
6. Tool ID parsed (mcp-serverId-toolName)
7. POST /api/mcp/tools/execute called
8. McpClient connects to MCP server
9. Sends tool execution request
10. Server returns McpToolResult
11. Result processed and returned to workflow

## CACHING STRATEGY

- TTL: 5 minutes (MCP_CONSTANTS.CACHE_TIMEOUT)
- Max entries: 1000
- Eviction: LRU (Least Recently Used)
- Cleanup: Every 5 minutes
- Manual refresh: Via button in settings
- Auto-refresh: Every 5 minutes if tools loaded
